04 / Evidence

Model record and limits

Paruthi, Tipu and colleagues reported a test-set R² of 0.929 and an RMSE of 2.71 MPa. The repository also reports an MAE of 2.09 MPa. These are the study’s reported results. Individual held-out measurements are unavailable in the source repository, which prevents an independent check of these scores.

The interface applies the seven features in the order recorded by the fitted scaler, then evaluates the 300 original trees in the browser. The port matched native XGBoost outputs on 503 numerical test cases. This comparison checks the implementation only. Confirm engineering decisions with material-specific experiments.
